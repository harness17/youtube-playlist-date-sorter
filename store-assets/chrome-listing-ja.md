# YouTube Playlist Date Sorter

YouTube のプレイリスト再生を、動画の投稿日順で見たいときのための拡張機能です。

表示中のプレイリスト項目から各動画の投稿日を取得し、古い投稿日順または新しい投稿日順に並び替えます。プレイリスト自体の保存順は変更せず、ページ上の表示と「次の動画へ」の移動先だけを拡張側で制御します。

## 主な機能

- プレイリストページとプレイリスト再生ページに対応
- 古い投稿日順 / 新しい投稿日順 / YouTube の通常順を切り替え
- 投稿日順の次の動画へ移動
- 自動移動の ON / OFF
- 日本語 / English の表示切り替え
- YouTube Data API キー不要

## 注意事項

- DOM に読み込まれているプレイリスト項目が対象です。
- YouTube の仕様変更により、取得や並び替えが一時的に動かなくなる場合があります。
- この拡張機能は YouTube の公式機能ではありません。
