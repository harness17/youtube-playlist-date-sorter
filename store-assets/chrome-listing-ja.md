# YouTube Playlist Date Sorter

YouTube のプレイリスト再生を、動画の投稿日順・タイトル順・再生時間順で見たいときのための拡張機能です。

表示中のプレイリスト項目から各動画の情報を使い、古い投稿日順、新しい投稿日順、タイトル順、再生時間の短い順・長い順に並び替えます。プレイリスト自体の保存順は変更せず、ページ上の表示と「次の動画へ」の移動先だけを拡張側で制御します。

## 主な機能

- プレイリストページとプレイリスト再生ページに対応
- 古い投稿日順 / 新しい投稿日順 / タイトル順 / 再生時間順（短い・長い）/ YouTube の通常順を切り替え
- 選択した順序の次の動画へ移動
- 自動移動の ON / OFF
- 日本語 / English の表示切り替え
- YouTube Data API キー不要

## 注意事項

- DOM に読み込まれているプレイリスト項目が対象です。
- YouTube の仕様変更により、取得や並び替えが一時的に動かなくなる場合があります。
- この拡張機能は YouTube の公式機能ではありません。
