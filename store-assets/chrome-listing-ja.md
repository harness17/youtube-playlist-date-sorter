YouTube Playlist Date Sorter は、YouTube のプレイリストページとプレイリスト再生ページで、表示中の動画を投稿日順・タイトル順・再生時間順に並び替える Chrome 拡張です。

プレイリストを古い投稿日順、新しい投稿日順、タイトル順、再生時間の短い順・長い順に並び替え、選択した順序に沿って次の動画へ移動できます。YouTube Data API や API キーは使わず、表示中のページと、投稿日順で必要になる各動画ページの公開日情報をもとに動作します。

主な機能:
・プレイリスト内の動画を投稿日順・タイトル順・再生時間順に並び替え
・古い投稿日順 / 新しい投稿日順の切り替え
・タイトル昇順 / 降順の切り替え
・再生時間の短い順 / 長い順の切り替え
・YouTube の通常表示順へ復元
・選択した順序で「次の動画へ」移動
・動画終了時に選択した順序で自動移動
・自動移動の ON / OFF を保存（初期状態は ON）
・プレイリストページと再生ページの両方に対応
・並び替え結果をプレイリストごとに保存
・日本語 / English 表示切り替え

この拡張は、プレイリスト本体の順序や YouTube アカウント上のデータを変更しません。ページ上の表示順と、拡張側の次動画移動だけを制御します。

注意:
・YouTube の DOM 構造変更により動作が影響を受ける場合があります。
・対象はページ上に読み込まれているプレイリスト項目です。
・長いプレイリストでは最大300件まで処理します。未読み込みの項目は対象外になる場合があります。
・この拡張は YouTube の公式機能ではありません。
